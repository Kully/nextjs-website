# Zyphr website

Static site: plain HTML, CSS and JavaScript with no build step.

- `index.html` is the single page.
- `css/` and `js/` hold the styles and scripts.
- `public/images/` holds logos, icons, client logos and project screenshots.

Preview locally from the repo root:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000.
